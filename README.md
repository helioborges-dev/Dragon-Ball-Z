# ⚡ Dragon Ball Z Kakarot – Interface Inspirada

![Status](https://img.shields.io/badge/status-concluído-brightgreen)

## 🚀 Sobre o Projeto

Interface desenvolvida como prática de Front-End, inspirada em sites de jogos
e no universo de Dragon Ball Z: Kakarot. O maior desafio do projeto foi
sincronizar áudio e interação: o volume da música de fundo reduz
automaticamente quando o trailer é reproduzido, e a troca de personagens é
acompanhada por um efeito sonoro de teletransporte, reforçando a dinâmica do
universo do anime. A criação do slider de imagens também exigiu mais lógica
do que os outros elementos da página.

## ✨ Funcionalidades

**Início**
- Links oficiais de compra nas plataformas Steam, Xbox, PlayStation e Nintendo
- Música de fundo com controle de volume automático ao reproduzir o trailer
- Formulário de cadastro com animação e som de teletransporte ao abrir e fechar
- Sobreposição de fundo ao abrir o formulário para destacar o conteúdo

**Notícias**
- Apresentação de trailer e lista de novidades do jogo

**Personagens**
- Card interativo com descrição de cada personagem
- Som de teletransporte ao trocar de personagem
- Personagem principal com animação de flutuação

**Destaques**
- Slider de imagens do jogo com navegação por setas e indicadores

**Geral**
- Layout responsivo para diferentes dispositivos
